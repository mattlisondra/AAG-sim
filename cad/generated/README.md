# Which file should I print?

For a replacement that screws directly onto the YAM wrist, use one of:

- `official-bracket-derived/yam_d435i_full_wrist_mount_left.stl`
- `official-bracket-derived/yam_d435i_full_wrist_mount_right.stl`

Those are complete, one-piece mounts. They preserve the source bracket's two
40 mm-pitch arm passages and add two open 45 mm-pitch D435i passages.

The top-level `yam_d435i_left.stl` and `yam_d435i_right.stl` files are optional
bolt-on adapters for retaining an already-installed D405 bracket. Their two
blind holes are heat-set-insert pockets by design. Do **not** mistake them for
the complete arm brackets.

Print `d435i_camera_interface_45mm_coupon.stl` first to verify the D435i hole
pitch before committing to either full print.
